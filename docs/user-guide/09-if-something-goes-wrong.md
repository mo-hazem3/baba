# 9 · If something goes wrong

Baba always tells you what is wrong **in plain words, in your language**, and what to do. Find the message (or the situation) below.

**Golden rule:** if you are not sure, **do not try things at random**. Make a backup copy of the file first (**Back up now**), then ask your owner or accountant.

---

## Opening Baba and the company

| What you see or what happens | What it means | What to do |
|---|---|---|
| Baba does not open when you double-click. | Baba may already be open (look at the taskbar) or still closing. | Look for the Baba window. If none, wait a minute, then double-click again. If it still does not open, restart the computer and try again. |
| **"The password is wrong, or this is not a Baba file."** | The file password is not right, or you picked a file that is not a Baba company. | Type the password again slowly (check Caps Lock and the language of the keyboard). Check the file name ends in `.baba`. If the password is truly lost, the file cannot be opened by anybody; open your last backup whose password you remember. |
| **"This company is already open in another window. Close it there first."** | Somebody (or you, in another window) has this file open. Only one at a time. | Close the other window (**Menu** → **Close company**). If nobody has it open, close Baba, wait a minute, and open it again. |
| **"The file was not found. It may have been moved or deleted."** | The company file is not where Baba remembers it. | Click **Open company file…** and look for the `.baba` file. Look in the Recycle Bin and in your backup folders. |
| **"This company was saved by a newer version of Baba. Please update Baba to open it."** | The file was last used on a computer that has a newer Baba. | Install the newer Baba (ask your supporter). Do not open the file with the old one. |
| **"A file with this name already exists. Choose a different name."** | You are creating (or restoring) into a name already in use. | Choose another name, so nothing is overwritten. |
| **"Baba cannot be reached. Please close it and start it again."** | The program had a problem inside. | Close Baba completely and start it again. Your work was saved as you went. |
| **"Something went wrong. Please try again."** | An unexpected problem. | Try once more. If it comes back, write down what you were doing and tell your supporter. |
| Windows says **"Windows protected your PC"** when installing. | Normal for a new program. | **More info** → **Run anyway**, if the file came from someone you trust. |

## Signing in

| Message | What to do |
|---|---|
| **"The user name or password is not right. Try again."** | Check the spelling. The user name is **not** case sensitive, the password **is**. If you forgot it, ask the owner to use **Reset password** for you. |
| **"Choose your own password"** (page) | Normal on your first sign-in or after a reset. Type the temporary password, then a new one twice. |
| **"Your role does not allow this."** | Your role does not include this action. Ask the owner if you need it. |
| The owner forgot their password | On the sign-in page click **I forgot the password**. Whoever knows the **company file password** can type it with the owner's user name and a new password. |

## Recording things

| Message | What it means and what to do |
|---|---|
| **"Debits and credits are not equal."** | A journal voucher's two sides differ. The page shows the difference: correct a line. |
| **"Line 2: choose the customer or supplier this is for."** | You used a customers' or suppliers' account. Pick whose it is. |
| **"Line 3: this is a group. Choose an account inside it."** | Group accounts only hold other accounts. Pick one underneath it. |
| **"This month is locked. Unlock it in Settings to make changes."** | The month was closed. If the change is really needed: **Settings** → **Locked months** → **Unlock** (the owner or accountant), change it, lock again. |
| **"This voucher has been checked against a bank statement, so it cannot be changed or deleted. Undo that reconciliation first."** | **Bank and cash** → **Reconcile** → **Undo the latest**, correct the voucher, then reconcile again. |
| **"This receipt or payment was set against invoices, so it cannot be changed. Delete it and make it again."** | Delete it and record it again. |
| **"This entry is made by Baba… and cannot be changed or deleted by hand."** | Baba made it (closing a year, depreciation...). Change what caused it, not the entry. |
| **"This invoice has a payment against it. Delete the receipt or payment first."** | A paid invoice is frozen. Delete the payment (or the credit note), then change the invoice. |
| **"Under the e-invoicing rules of your country an issued invoice cannot be changed or deleted. Make a credit note instead."** | Open the invoice → **Turn this into:** → **Credit note**. |
| **"There is not enough stock for this quantity."** | You are selling or moving more than Baba has. Check the quantity and the warehouse; do a stock count if the shelf and Baba disagree. |
| **"Posting needs approval in this company. Use Send for approval instead."** | Your company asks for approval. Click **Send for approval**; someone with the right will post it. |
| **"This is no longer waiting. It may have been decided or changed already."** (Approvals) | Someone else already decided, or the sender changed it. Refresh the page. |

## Importing from Excel

| Message | What to do |
|---|---|
| **"The file could not be read. Use a CSV or an Excel (.xlsx) file."** | Save your list as **Excel Workbook (.xlsx)** or **CSV**. |
| **"There is no Name column."** (or Code, Date, Amount...) | The first row must have the column names from Baba's template. Download the template and copy your data into it. |
| It lists lines with problems and **imports nothing** | That is on purpose: a half-imported list is hard to fix. Correct the lines named, and import again. |

---

## Printing and files

| Situation | What to do |
|---|---|
| **PDF** does not open | Baba opens PDFs in its own small window. Look for it in the taskbar. You can also choose **Excel** or **CSV**. |
| Excel asks where to save | That is Windows asking: choose a folder. |
| Numbers look different in Excel | They are real numbers. Format the column in Excel if you want to see decimals differently. |
| Arabic letters look wrong in a printout | Choose the **Language** of the printout again (**Arabic**, **English** or **Both**) before you click **PDF**. |

## Something is wrong with the numbers

1. Check the **dates** you chose at the top of the report.
2. **Click the amount**: Baba shows the entries behind it.
3. Look for **draft** vouchers (they are not in the reports until posted).
4. Look at the **Trial balance**: do the two sides agree?
5. Reports that **check themselves** (stock valuation, fixed assets, tax return) show a warning when they disagree with the books. Tell your accountant.
6. The owner can open the **Audit log** to see who changed what and when.

---

## Getting help

- On every page, the **Help** button next to the title explains it in a few lines.
- Menu → **Keyboard shortcuts** lists the quick keys (for example **Ctrl+S** to save).
- Write down what you were doing, what you expected, and what Baba said (copy the message words exactly). A photo of the screen is even better. Send it to the person who supports Baba for you.

### Before you ask for help, make a backup

**Summary** → **Back up now**. If anything is to be repaired, the backup is the safety net.
