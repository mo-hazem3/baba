# 10 · شرح الكلمات

يستخدم المحاسبون كلمات كثيرة. هذه التي تقابلها في بابا بلغة بسيطة، بالترتيب الذي يلقاها به النشاط.

---

## الأساسيات

| الكلمة | بلغة بسيطة |
|---|---|
| **ملف الشركة** | الملف الواحد (ينتهي بـ`.baba`) الذي فيه كل بيانات نشاطك. مقفل بـ**كلمة مرور الملف**. |
| **النسخة الاحتياطية** | نسخة كاملة من ملف الشركة. إذا تعطل الحاسوب أنقذتك. |
| **الحساب** | مكان له اسم يُعدّ فيه المال، مثل «الصندوق» و«الإيجار» و«المبيعات». |
| **دليل الحسابات** | قائمة كل حساباتك. |
| **حساب مجموعة** | حساب لا يحوي إلا حسابات أخرى (كالمجلد). تسجّل على الحسابات التي داخله. |
| **السند** | تسجيل واحد لشيء حدث بالمال: **سند قبض** (مال داخل) أو **سند صرف** (مال خارج) أو **قيد يومية** (تسوية) أو **تحويل** (بين حساباتك). |
| **المسودة** | سند أو فاتورة حفظتها ولم تجعلها حقيقية بعد. ليست في تقاريرك. |
| **الترحيل** (أو **حفظ وترحيل**) | جعله حقيقيًا في الدفاتر. يأخذ رقمًا. |
| **المدين** و**الدائن** | طرفا القيد. كل قيد مدينه ودائنه متساويان؛ بهذا تبقى الدفاتر متوازنة. يحذّرك بابا إذا لم يتساويا. |
| **السنة المالية** | سنتك المحاسبية. غالبًا من يناير إلى ديسمبر، لكن يمكن أن تبدأ في أي شهر. |
| **الشهر المقفل** | شهر انتهى. لا يستطيع أحد إضافة شيء مؤرخ فيه أو تغييره أو حذفه. |
| **الأرصدة الافتتاحية** | ما كان عند النشاط يوم بدأت مع بابا. |

## من يدين ومن يُدان له

| الكلمة | بلغة بسيطة |
|---|---|
| **العميل** | من يشتري منك وقد يدين لك بمال. |
| **المورد** | من تشتري منه وقد تدين له بمال. |
| **الذمم المدينة** («مستحق لك») | المال الذي ما زال على العملاء أن يدفعوه لك. |
| **الذمم الدائنة** («مستحق عليك») | المال الذي ما زال عليك أن تدفعه للموردين. |
| **أعمار الديون** | قائمة تبيّن عمر كل دين: 0–30 يومًا و31–60 و61–90 وأكثر من 90. الديون القديمة هي الخطرة. |
| **كشف الحساب** | قائمة كل ما اشتراه عميل أو مورد ودفعه، مع الرصيد. |
| **الحد الائتماني** | أقصى ما يُسمح للعميل أن يدين لك به. يحذّرك بابا إن تجاوزته فاتورة. |
| **شروط السداد** | عدد الأيام التي يملكها العميل ليدفع. |

## البيع والشراء

| الكلمة | بلغة بسيطة |
|---|---|
| **عرض السعر** | سعر تعرضه. لا يغيّر شيئًا في الدفاتر. |
| **الأمر** | وافق عليه عميل (أو أنت). لا يغيّر شيئًا في الدفاتر. |
| **إذن التسليم** | ورقة تقول إن البضاعة سُلِّمت. |
| **الفاتورة** | طلب دفع. هي ما يجعل العميل يدين لك. |
| **فاتورة المورد** | فاتورة مورد إليك. |
| **الإشعار الدائن** | عكس الفاتورة: تخفض ما يدين به العميل (مرتجع أو خطأ). |
| **الإشعار المدين** | الشيء نفسه من جهة المورد. |
| **الإصدار** | جعل الفاتورة نهائية وإعطاؤها رقمها. |
| **رمز الضريبة** | قاعدة مثل «النسبة العادية 15%» يستطيع السطر أن يحملها. |
| **ضريبة القيمة المضافة / الإقرار الضريبي** | الضريبة التي حصّلتها ناقص الضريبة التي دفعتها، لتبلغ بها مصلحة الضرائب. |
| **سعر الصرف** | كم وحدة من عملتك تساوي وحدة واحدة من عملة أجنبية. |
| **ربح أو خسارة فروق العملة** | الفرق حين تغيّر السعر بين الفاتورة والدفع. يسجّله بابا عنك. |
| **قائمة الأسعار** | مجموعة أسعار يأخذها عميل مختار. |

## البنك

| الكلمة | بلغة بسيطة |
|---|---|
| **التسوية** | التحقق، سطرًا بسطر، أن سجلاتك توافق كشف البنك. |
| **رصيد الكشف** | الرصيد الختامي الذي طبعه البنك. |
| **الفرق** | ما لم يُفسَّر بعد. يجب أن يكون صفرًا قبل أن تنهي. |

## المخزون

| الكلمة | بلغة بسيطة |
|---|---|
| **صنف المخزون** | منتج تعدّه. |
| **المستودع** | مكان تحفظ فيه المخزون. |
| **المتوفر** | كم عندك الآن. |
| **متوسط التكلفة** | ما كلفته الوحدة الواحدة في المتوسط، بما فيه الشراء القديم والجديد. |
| **الجرد** | عدّ الرفوف وإخبار بابا بالأعداد الحقيقية. |
| **حدّ إعادة الطلب** | الكمية التي يحذّرك بابا عندها لتشتري المزيد. |
| **تكلفة البضاعة المباعة** | ما كلّفتك البضاعة التي بعتها. يسجّلها بابا حين تصدر الفاتورة. |

## الأشخاص والأجور

| الكلمة | بلغة بسيطة |
|---|---|
| **القسيمة** | كشف راتب موظف واحد لشهر واحد. |
| **مسيّر الرواتب** | قسائم الشهر للجميع. |
| **التأمينات الاجتماعية** | الاشتراكات من الموظف ومن صاحب العمل التي يطلبها قانون دولتك. |
| **نهاية الخدمة** | ما يستحقه الموظف حين يغادر، وهو يتراكم على السنين. يحتفظ بابا بـ**مخصص**: مال محجوز في الدفاتر. |
| **مطالبة المصروفات** | يطلب موظف أن يُردَّ له ما دفعه للنشاط. |
| **الأصل الثابت** | معدات ومركبات وأثاث تدوم سنين. |
| **الإهلاك** | توزيع تكلفة أصل على عمره. يرحّله بابا كل شهر. |
| **الموازنة** | الخطة: كم تتوقع أن تكسب وتنفق كل شهر. |
| **مركز التكلفة** | علامة (فرع أو مشروع) تتيح لك رؤية الربح لكل منها. |

## التقارير

| الكلمة | بلغة بسيطة |
|---|---|
| **ميزان المراجعة** | كل حساب بمجموعه. يجب أن يتفق الطرفان. |
| **الأرباح والخسائر** | ما كسبته ناقص ما أنفقته في فترة. |
| **الميزانية العمومية** | ما تملكه وما عليك وما يبقى للمالكين، في تاريخ واحد. |
| **دفتر الأستاذ العام** | كل قيد على كل حساب. |
| **الأرباح المحتجزة** | أرباح سنوات سابقة بقيت في النشاط. |
| **إقفال السنة** | نقل ربح السنة أو خسارتها إلى الأرباح المحتجزة وقفل السنة. |

## من يستخدم بابا

| الكلمة | بلغة بسيطة |
|---|---|
| **المستخدم** | شخص يسجّل الدخول. |
| **الدور** | مجموعة صلاحيات تُعطى للمستخدم: مدير النظام أو محاسب أو مبيعات أو أمين مخزن أو مشاهد، أو دور تصنعه الشركة. |
| **الموافقة** (الصلاحية) | حق جعل الأشياء نهائية (الترحيل والموافقة والقفل). |
| **الموافقة** (النظام) | عند تفعيله يرسل من لا يملك صلاحية الموافقة عمله لشخص آخر ليرحّله. |
| **سجل المراجعة** | سجل كل تغيير: من ومتى والقيم القديمة والجديدة. لا يستطيع أحد تعديله. |
